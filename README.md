# Анализ и прогноз успеваемости студентов ИБ

Учебная консольная программа на C++17. Записи хранятся в бинарном файле `students.dat`; отчёт выгружается в `report.txt`. На первом запуске задаётся локальный пароль, далее программа проверяет его хеш из `auth.dat`.

## Сборка

Требуется компилятор C++17 и CMake 3.16 или новее:

```sh
cmake -S . -B build
cmake --build build --config Release
```

## Структура

- `main.cpp` — меню и ввод;
- `auth.*` — первичная настройка и проверка пароля;
- `grade_store.*` — формат бинарной базы и операции с записями;
- `reports.*` — сводки, отбор риска, сортировка и прогноз.
