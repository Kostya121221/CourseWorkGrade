# Анализ и прогноз успеваемости студентов ИБ

Учебная консольная программа на C++17. Записи хранятся в бинарном файле `students.dat`; отчёт выгружается в `report.txt`. На первом запуске задаётся локальный пароль, далее программа проверяет его хеш из `auth.dat`.

## Сборка

Требуется компилятор C++17 и CMake 3.16 или новее:

```sh
cmake -S . -B build
cmake --build build --config Release
```

Запустите созданный исполняемый файл из каталога, в котором должны храниться `students.dat` и `auth.dat`.

## Функции

- добавление, просмотр, изменение и удаление записей;
- поиск записей по учебной группе;
- бинарное хранение и повторная загрузка данных;
- групповой отчёт со средним баллом, посещаемостью и числом студентов группы, попавших в зону риска;
- сортировка по оценке и фильтр риска (оценка не выше 3, посещаемость ниже 60% или менее 3 лабораторных);
- индивидуальная объяснимая оценка риска по ID: уровень и причины на основе оценок, посещаемости и выполненных лабораторных;
- экспорт сводки в текстовый файл;
- линейная экстраполяция семестровых средних на следующий семестр.

Поля записи: ID, ФИО, группа, дисциплина, номер семестра, оценка (2–5), посещаемость (0–100%), число выполненных лабораторных (0–30). Демонстрационные записи вводит пользователь; искусственный набор данных программа не подменяет реальными результатами.

## Ограничения и безопасность

Прогноз носит иллюстративный характер: это линейный тренд по средним оценкам семестров, а не валидированная модель. При наличии одного семестра возвращается последнее среднее. Для содержательной проверки прогнозов нужны согласованные реальные обезличенные данные.

Хеширование в `auth.cpp` дано только как учебная демонстрация требования о непередаче пароля в открытом виде. FNV-1a не является криптографической функцией хранения паролей; в реальной системе следует применять специализированный алгоритм вроде Argon2id с индивидуальной случайной солью и параметрами стоимости. Файл данных содержит персональные поля, поэтому используйте только вымышленные/обезличенные сведения и ограничьте доступ к каталогу.

## Структура

- `main.cpp` — меню и ввод;
- `auth.*` — первичная настройка и проверка пароля;
- `grade_store.*` — формат бинарной базы и операции с записями;
- `reports.*` — сводки, отбор риска, сортировка и прогноз.

ТЗ из комплекта пока не утверждено и содержит общий шаблон функций для бинарных файлов. До защиты нужно согласовать с руководителем выбранную предметную обработку, алгоритм хеширования, ограничения на контейнеры и требуемый компилятор.
